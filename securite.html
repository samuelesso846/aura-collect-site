Vos codes de secours

Notez-les maintenant. Ils ne seront plus jamais affichés. Chaque code ne sert qu'une fois, si vous perdez votre téléphone. Conservez-les hors de votre téléphone (papier, coffre de mots de passe).

Désactiver la double authentification

Par sécurité, confirmez avec votre mot de passe et un code (application ou code de secours).
